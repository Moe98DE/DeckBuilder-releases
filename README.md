# DeckBuilder downloads

Signed Windows and Linux installers and update manifests for DeckBuilder, an offline Commander deckbuilder.

[Download the latest release](https://github.com/Moe98DE/DeckBuilder-releases/releases/latest)

- Windows: **DeckBuilder-Windows-x64-Setup.exe** (recommended), or **DeckBuilder-Windows-x64.msi**.
- Linux: **DeckBuilder-Linux-x86_64.AppImage**, **DeckBuilder-Linux-amd64.deb**, or **DeckBuilder-Linux-x86_64.rpm**.
- Installation instructions are included as **INSTALL.md** in each release.

This repository contains downloads and public installation instructions only. The application source is maintained separately. GitHub's automatic source archives do not contain the application.

The app checks this repository for updates without requiring a GitHub account. Update installers are signed and verified by DeckBuilder before installation.

Downloads will appear here after the first build using this repository completes.
